# iNutri

**iNutri** is an application built for nutritionists to create and manage personalized meal plans. Developed as a final year project at the University of Buenos Aires, iNutri combines clinical nutrition knowledge with digital tools to support professionals in their daily work.

## 🚀 Features

- **Multi-step meal plan builder**: Input patient goals, calculate energy requirements (IPC, VCT), and build personalized meal plans.
- **Editable food catalog**: Maintain a structured database of foods with full nutritional profiles.
- **Meal organizer**: Assign foods to meals and specify preparation methods.
- **Patient agenda**: Manage consultations and track patient history.
- **AI tools**:
  - Suggest food plans based on patient food preferences, allergies, illnesses and personal goals.
  - Suggest meal ideas based on goals or constraints.

## 🧰 Tech Stack

- **Frontend**: Angular
- **Backend**: Java (Spring Boot)
- **Database**: PostgreSQL
- **AI Integration**: OpenAI API
- **DevOps**: Docker, GitHub Actions
